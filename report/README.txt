# 🚀 AWS IAM & EC2 Security Access Control Project Report

This repository contains the detailed project documentation for the **AWS IAM & EC2 Security Access Control Project**, completed by **Mohammad Athar Shareef** as part of a **Master’s in Cybersecurity** portfolio.

---

## 📘 Report Overview

The report titled **AWS-IAM-EC2-Project-Report-With-Screenshots.pdf** demonstrates a complete, hands-on implementation of secure cloud access control using **AWS Identity and Access Management (IAM)** and **EC2 (Elastic Compute Cloud)**.

This project focuses on building a **secure, role-based access model** using tag-based IAM policies, ensuring controlled access between **development** and **production** environments.

---

## 📂 Report Contents

The documentation covers:

- 🔹 Project objectives and cloud architecture design  
- 🔹 Tools and AWS services utilized  
- 🔹 Step-by-step implementation with annotated screenshots  
- 🔹 IAM Policy JSON configuration and explanations  
- 🔹 Access control testing — restricted vs. allowed scenarios  
- 🔹 Cloud security best practices and future improvement areas  

---

## 🎯 Purpose

This project demonstrates the real-world application of **AWS IAM** and **EC2** in implementing secure cloud operations. It showcases:

- ✅ Role-based access control (RBAC)  
- ✅ Principle of Least Privilege  
- ✅ Environment isolation (Production vs. Development)  
- ✅ Tag-based conditional IAM policies  
- ✅ Real-world AWS configuration and security testing  

This practical approach reflects key cybersecurity concepts such as **access governance**, **defense-in-depth**, and **least privilege enforcement** — all essential in cloud security management.
