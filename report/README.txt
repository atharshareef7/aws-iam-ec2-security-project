# AWS IAM & EC2 Security Access Control Project Report

This folder contains the detailed project report for the **AWS IAM & EC2 Access Control Project** completed by **Mohammad Athar Shareef**.

## 📘 Report Contents

The report titled **"AWS-IAM-EC2-Project-Report-With-Screenshots"** includes:
- Project overview and objectives
- Tools and AWS services used
- Step-by-step implementation with screenshots
- IAM Policy JSON and configuration details
- Results showing restricted access to production and allowed access to development
- Security best practices and future improvements

## 🧠 Purpose

This report demonstrates practical implementation of **AWS Identity and Access Management (IAM)** and **EC2 instance-level security** using tag-based policies. It serves as a hands-on cloud security project showcasing:
- Role-based access control
- Principle of least privilege
- Environment isolation (Production vs Development)
- Real-world AWS configuration and testing
